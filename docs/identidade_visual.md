# Identidade visual do MVP

## Direção adotada

Continuidade do visual existente: interface escura, marca tipográfica AVScope, símbolo geométrico simples e azul como cor principal. A aplicação prioriza números e nomes de aeroportos; não depende de fotografias ou fontes externas.

| Uso | Cor |
| --- | --- |
| Fundo | `#0B0D10` |
| Superfícies | `#111419` |
| Campos e superfícies elevadas | `#171B21` |
| Texto principal | `#F4F6F8` |
| Texto secundário | `#929AA5` |
| Destaque e séries principais | `#6EA8FE` |
| Alertas | `#E7B65A` |
| Variação positiva | `#45C486` |
| Variação negativa | `#E36D76` |

Tipografia: Inter quando disponível, com fallback para Segoe UI e fontes do sistema. Os números usam alinhamento tabular nos indicadores. As mensagens explicam ausências e anomalias por texto, sem depender somente de cores.

## Comportamento

Navegação em três áreas: Explorar rota, Descobrir mercados e Sobre os dados. No celular, filtros e botões são empilhados; indicadores ocupam uma grade menor. Tabelas largas preservam todas as colunas com rolagem horizontal interna.

Links e controles mantêm foco de teclado. Animações respeitam a preferência de movimento reduzido. Rota e período permanecem destacados para dar contexto aos números. Esta é a identidade consolidada para esta edição do MVP; não inclui um manual de marca corporativo ou registro de marca.
